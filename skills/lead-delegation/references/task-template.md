# 子 Agent 任务模板

复制所需字段，填入实际内容。简短任务可把目标、范围、产物和验收方式写在同一段。

## 目标与验收

- 用户要达成的结果
- 可观察、可检查的完成条件

## 上下文与依赖

- 已核实的事实及证据，例如文件位置、规格链接、测量结果
- 需要先核实的假设
- 要依赖的任务产物及其可用版本

## 工作范围与授权

- 仓库、基线版本、工作区及可写范围
- 需要保留的既有改动、并行任务负责的文件或共享资源
- 相关项目规则与已授权操作

## 交付与验证

- 交付物及位置。实现任务提供变更位置和适用的版本标识。调研给出结论、引用与未决问题。审查给出发现、影响与复核依据。
- 项目适用的验证命令或证据要求
- 回报实际执行的检查及结果、未验证的范围，以及阻塞时所需的决定或输入
