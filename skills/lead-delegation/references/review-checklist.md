# 子 Agent 产出验收清单

- **用户目标**。逐项对照验收标准，读实际 diff、报告或证据。检查交付是否覆盖用户走的入口和明确约定的边界。
- **改动范围**。检查基线、提交、工作区 diff 和新增文件，确认并行任务的改动都归到正确的工作项，已有用户改动完整保留。
- **契约与行为**。检查改动触及的调用方、共享接口和失败路径。有跨任务依赖时，确认依赖双方使用同一个契约版本。
- **证据**。将结果关联到实际验收的工作区状态或提交。证据缺失、版本不一致或集成改变了行为时，补跑受影响的检查。调研和审查结果需能回到原始证据。
- **处置**。验收通过时记录产物和验证来源。需要返工时按“位置 → 影响 → 期望结果”指出问题并重新验收。遇到阻塞时记录缺少的输入或授权，继续处理独立任务。
